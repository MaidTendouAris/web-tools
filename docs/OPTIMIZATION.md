# 浏览器性能与资源管理

项目仍是无后端的静态工具集；运行时不需要 npm 或构建。TypeScript、Node.js 和 Playwright 仅用于开发检查，发布页面直接加载仓库中的 JavaScript。

## 图片处理

- 压缩结果绑定输入与参数的任务编号。新输入或参数变更立即禁用旧输出下载，过期编码回调不能覆盖当前结果。
- 裁剪预览最长边为 1200px；点击导出时才生成目标尺寸画布。
- 输出画布采用 1600 万像素、单边 8192px 的保守预算。超出时暂停原尺寸输出，并提供按比例缩小的明确操作；压缩、裁剪和拼接均适用。
- 画布编码失败会显示可重试提示，临时导出画布在完成后释放。

预算不是浏览器内存上限。解码原图、保留输入图片、编码器和浏览器自身还会占用额外内存；低内存设备可能仍需更小的输入或更少的图片。

## PDF 页面预览

- 只为可见区域及附近 100px 范围生成嵌入预览；离开范围的嵌入元素会移除。
- 每次生成一页，页间让出主线程。同一页面、旋转角度的任务合并，过期结果丢弃。
- 最多保留两个已解析的源文档。闲置预览 URL 缓存以 16 项为目标，当前可见页面和全屏预览按需保留。
- 删除页面、替换文件及移除输出时回收相应对象 URL。导出与文件导入期间阻止重入，失败后恢复操作。

源 PDF 的首次解析与导出仍由 pdf-lib 在当前页面执行，极大的 PDF 仍可能短暂影响响应。缩略图依赖浏览器内置 PDF 查看能力。

## 本地资源完整性

下载、导入与读取缓存时，均将资源内容与 shared-resources.ts 中固定的 SHA-256 比较。支持版本：

| 资源 | 版本 |
| --- | --- |
| FFmpeg Core JS / WASM | 0.12.10 |
| pdf-lib | 1.17.1 |

只有相同文件名不足以通过验证。其他版本或修改过的文件会被拒绝，已存在的有效缓存不会被错误导入覆盖。资源损坏或版本不符时，可在工具页点击“修复资源”重新下载。

HTTPS 和支持 WebCrypto 的环境使用原生 SHA-256；普通 HTTP 环境使用按块让出主线程的 JavaScript 实现。旧缓存也按内容重新验证，不信任缓存中保存的验证标记。

升级依赖时必须同时更新 URL 与 SHA-256，并运行资源和真实处理回归。第三方运行库和测试素材存放于忽略目录，不提交到仓库。许可证见 [第三方说明](./THIRD_PARTY_NOTICES.md)。

## 共享设置与错误恢复

shared-preferences.ts 统一语言、主题的默认值、旧键兼容与跨标签页同步。浏览器禁止 localStorage 时，选择保留在当前页面内存中，不影响工具启动；刷新后不能保证保留。

shared-controls.ts 提供公共错误解释与“移除输出”按钮。音视频错误保留有限的 FFmpeg 诊断，区分可识别的内存、格式和参数问题；移除输出会释放下载对象 URL。取消和任务结束继续终止 Worker，下一次处理可重新初始化。

## 音频导出与字幕兼容性

- 切换音量增益的输出格式时同步编码参数，避免将 MP3 编码写进 WAV，或在 M4A/OGG/FLAC 中使用错误的编码器。
- 固定 FFmpeg Core 0.12.10 的 libopus 默认 20ms 帧在立体声输入下可触发越界异常；默认使用 10ms 帧，保留立体声。高级参数显式设置的帧长仍由用户控制。运行时越界异常不再直接解释为内存不足。
- 内部输出路径使用绝对路径，防止以连字符开头的合法文件名被当作 FFmpeg 参数。
- MP3 字幕使用 [ID3v2.3](https://id3.org/id3v2.3.0) 的 UTF-16 SYLT 同步歌词和带 LRC 时间戳的 USLT 回退歌词，时间精确到毫秒。已有 MP3 直接复制音轨，保留标题及支持的附加封面，避免再次有损压缩。
- MP3 导出结果另提供同名 LRC、VTT 文件。将外部字幕与音频放在同一文件夹；如果播放器未自动载入，可手动加载。需要标准内嵌字幕轨时选择 MKV。

ID3 歌词标签与容器中的字幕轨不同。VLC 3 只将 USLT 读取为歌词元数据，不显示为字幕轨；VideoLAN 开发分支在 [2026 年 4 月的提交](https://mailman.videolan.org/pipermail/vlc-commits/2026-April/072966.html) 中才新增 SYLT 播放支持。PotPlayer 的显示取决于版本及歌词显示设置；不能保证每个播放器都自动显示 ID3 歌词。导出器写入合法标签并提供外部字幕，不把文件格式支持等同于播放器显示支持。

开发验证命令与覆盖范围见 [测试说明](../tests/README.md)。
